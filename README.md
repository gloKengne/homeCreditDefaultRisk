# homeCreditDefaultRisk
It's never late to start a project, right?
New challenge!!

This banking project wants to broaden finacial inclusion for the unbanked population. These people struggling to get loans but don't have a sufficient or existeny credit histories.

## The Problem??
Unfortunately for this population, there exist untrustworthy lenders. A population to whom Home Credit does not want to fall on because their repayment abilities are doubtful.

## The Solution??
Making use of a variety of alternative data to predict their clients' repayment abilities. Statistics, machine learning, let's make use of these methods to unlock the full potential of this data !!!
